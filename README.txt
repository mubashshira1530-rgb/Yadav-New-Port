HOW TO OPEN (IMPORTANT)
1. Download this ZIP file.
2. In Windows File Explorer, right-click it and select "Extract All".
3. Open the extracted folder in Visual Studio Code (File > Open Folder).
4. Open index.html, right-click inside the editor, and choose "Open with Live Server".
   Alternatively, double-click index.html from the extracted folder to open it in a browser.
